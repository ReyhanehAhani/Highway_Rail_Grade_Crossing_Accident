# Highway–rail incidents — dashboard wireframe (Figma)

## Frame: National overview

| Zone | Content |
|------|---------|
| KPI strip | YoY incident count, share severe (your definition), states in alert (top N). |
| Map (optional) | `State` choropleth or ranked bar if map licensing is heavy. |
| Trend | Incidents by `Year` and `Quarter` / season. |
| Filters | State, light condition, warning device type, road condition. |

## Frame: Severity drivers

- Stacked bar: severity class × key categorical (device type or surface).
- Small multiples for hour-of-day vs. season (if features exist).
